    Get exact specs

    The browser test can’t see your CPU cores and clock speed, full memory, graphics memory, or free disk space. One command can.

    The command only reads information. It installs nothing, changes nothing, sends nothing, and doesn’t need administrator rights. Every line is shown here so you can check it.

    1. Copy the command. Use the button below.
    2. Open PowerShell. Press the Windows key, type PowerShell, and press Enter. Don’t choose “Run as administrator.”
    3. Paste and run. Right-click inside the blue or black window (or press Ctrl+V), then press Enter. If a box warns that you’re pasting multiple lines, choose Paste anyway.
    4. Wait for the yellow line. After a few seconds PowerShell prints “Your specs…” and copies the result for you.
    5. Come back here and paste into the box below with Ctrl+V.
    PowerShell · Windows 10 and 11

    1. Copy the command. Use the button below.

    3. Paste and run. Press Ctrl+Shift+V, then Enter.
    4. Copy the result. Select the whole line starting with CCSPECS and press Ctrl+Shift+C.
    5. Come back here and paste into the box below.

    Find your
    specs

    Two minutes, no downloads

    Everything the browser test can't see is listed in your system settings. Pick your operating system for step-by-step directions.

    ← Back to device test

    OS version

    Open Settings → System → About. Under Windows specifications, read the Edition (Windows 10 or 11) and Version (for example 24H2).

    Processor and cores

    Press Ctrl + Shift + Esc to open Task Manager, then choose Performance → CPU. Use the number next to Logical processors. System type on the About page shows x64 or ARM.

    AVX2

    Search your processor model on the Intel or AMD website and look under Instruction Set Extensions. Intel Core 4th generation (2013) and later, and all AMD Ryzen chips, support AVX2.

    Memory (RAM)

    Settings → System → About lists Installed RAM.

    Graphics and VRAM

    In Task Manager, open Performance → GPU. Laptops with two GPUs show GPU 0 and GPU 1. The one with Dedicated GPU memory above 1 GB (usually NVIDIA or AMD Radeon RX) is your dedicated card.

    Free space and drive type

    Open File Explorer → This PC for free space. Task Manager → Performance → Disk shows SSD or HDD in the heading.

    macOS version

    Choose the Apple menu → About This Mac. The macOS name and number (for example Sequoia 15.5) appear under the chip.

    Chip

    The same window shows Chip: Apple M1 through M4 (or later) is Apple silicon. A Processor line that says Intel means an Intel Mac, which current MATLAB no longer supports.

    Memory

    About This Mac lists Memory. Apple silicon shares this memory with graphics.

    Graphics

    Apple silicon graphics are built in and meet both programs' Mac requirements. On an Intel Mac, choose More Info → System Report → Graphics/Displays for VRAM.

    Free space

    Open System Settings → General → Storage. All Macs sold since 2020 use SSDs.

    Cores and AVX2

    Not needed on a Mac: neither vendor lists a core count or instruction set for macOS.

    Distribution

    Run cat /etc/os-release and read PRETTY_NAME.

    Processor and cores

    Run lscpu. Model name is your CPU and CPU(s) is the logical core count.

    AVX2

    Run grep -o -m1 avx2 /proc/cpuinfo. If it prints avx2, you have it.

    Memory

    Run free -h and read the total column on the Mem row.

    Graphics and VRAM

    Run lspci | grep -iE 'vga|3d'. For NVIDIA cards, nvidia-smi shows total memory.

    Free space and drive type

    df -h ~ shows free space in your home folder. In lsblk -d -o name,rota, ROTA 0 means SSD.
