#### Minimum
_Minimum_ is relevant for legacy hardware or newer ultraportable, low-power devices. These devices are generally sufficient for _basic modeling activities_ like learning CAD or slicing STLs, but may struggle to navigate hundred-component assemblies, long chains of parametric design history, or mission-critical toolpaths, as well as the high resolution graphics associated with these workflows.
#### Recommended
_Recommended_ reflects a _minimum hardware performance baseline_ for professionals and those with mission-critical, resource-heavy workflows with local processing, large assemblies, or longtail parametric history, rendered with high quality canvas graphics and DPI scaling.
Tool path generation and simulation are multi-threaded operations that will benefit from an increase in core count. The user interface and many modeling operations will benefit from an increase in single-threaded clock speed.
#### About Certified Graphics Hardware
Cards and drivers listed on the[Certified Graphics Hardware](https://www.autodesk.com/support/system-requirements/certified-graphics-hardware/fusion-360) page have been tested by card vendors or product teams, and results have been reviewed by Autodesk product teams. The tests verify that the hardware supports the product features. Cards and drivers not listed may still work with the product, but Autodesk has not yet received or verified test results.

### Microsoft Windows requirements
**!****Click to expand -**Media Feature Pack is required before installing Autodesk Fusion on Windows How to install Media Feature pack for Windows:
1. Close Autodesk Fusion.
2. Go to[Media Feature pack for Windows](https://support.microsoft.com/en-us/topic/media-feature-pack-list-for-windows-n-editions-c1c6fffa-d052-8338-7a79-a4bb980a700a).
3. Select the MFP for your Windows version.
4. Install media pack.
5. Restart machine (recommended).
6. Start Autodesk Fusion.
