### Operating System macOS Golden Gate (27)
macOS Tahoe (26)
macOS Sequoia (15)
**Note:**macOS Sonoma is no longer supported.
### Processor**Minimum**: Any A-series or M-series chip**Note:**MATLAB is no longer available for Macs with Intel processors
### RAM**Minimum**: 8 GB
**Recommended**: 16 GB
### Storage 3.7 GB for just MATLAB
4-6 GB for a typical installation
17 GB for an all products installation
An SSD is strongly recommended
### Graphics Any Mac able to run macOS Sonoma has a GPU able to run MATLAB.
GPU acceleration with Parallel Computing Toolbox is [not available on macOS](https://www.mathworks.com/matlabcentral/answers/442324-can-i-use-matlab-with-an-nvidia-gpu-on-macos-10-14-mojave-and-newer).
